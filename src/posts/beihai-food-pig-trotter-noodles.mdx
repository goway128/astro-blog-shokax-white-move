北海的饮食和这座城市一样，靠海，也靠市井生活。早晨的猪脚粉店冒着热气，越南卷粉在铁盘上铺开薄薄一层米浆，椒盐皮皮虾端上桌时还带着油香，糖水铺则把绿豆、海带和红糖慢慢熬进碗里。

如果要用一道食物介绍北海，我会选猪脚粉。它没有复杂的摆盘，一碗粉、一块猪脚、几勺浓汤就能撑起一顿早餐。味道扎实，价格亲民，也保留着北海街头最常见的生活气息。

## 从一碗粉开始

早上七点左右，街边粉店已经坐满了人。店主从卤锅里夹出一块猪脚，切开后盖在刚烫好的米粉上，再舀入汤汁。猪脚表面呈棕红色，皮肉带着油亮的光。白色米粉浸入汤后颜色稍深，旁边的葱花、酸菜或腌萝卜把整碗粉点亮。

在北海，很多人的一天从一碗猪脚粉开始。米粉吸住卤汤，猪脚炖到软糯，一口下去有肉香，也有米粉的清爽。这碗早餐简单，却能让人记住北海街头的味道。

## 色香味俱全

猪脚粉的吸引力来自几个很直接的感官信号。

**色泽**。猪脚经过卤制后呈棕红色，皮层透亮，瘦肉部分颜色更深。汤汁不是清水般透明，而是带着浅褐色。米粉保持白净，葱花和酸菜补上绿色与黄色。

**香气**。热汤先送出肉香，靠近后能闻到八角、桂皮、酱油和葱花的味道。香料负责去腥，不能盖过猪肉本身。卤味太重时，整碗粉容易发苦。

**味道**。第一口汤带咸鲜，随后是卤汁的微甜。猪脚的脂香比瘦肉重，酸菜或腌萝卜可以削弱油腻感。米粉味道淡，负责吸收汤汁。

**口感**。猪皮软糯，筋膜保留一点韧性，瘦肉能用筷子分开。米粉柔软但不能泡烂。吃得太慢时，米粉继续吸汤，口感会从爽滑变得绵软。

## 我为什么推荐猪脚粉

#### 三个特点

第一，北海人把米制主食吃出了自己的节奏。米粉烫熟快，适合早餐和午间简餐，也能和卤肉、海鲜、酸菜搭配。

第二，味道重但层次清楚。猪脚负责脂香，卤汤负责咸鲜，酸菜负责解腻。每样东西都有明确作用，没有复杂装饰。

第三，它和日常生活靠得近。你不需要等节日，也不用提前订位。早市附近、居民区路口和老街旁边都可能遇到一间粉店。

猪脚粉也适合第一次到北海的人。它常见、实惠，味道有辨识度，不需要复杂的吃法。

## 一碗猪脚粉有哪些营养

一份猪脚粉通常包含米粉、猪脚、汤汁和少量配菜。不同店铺的分量和做法差异很大，下面只分析主要营养来源。

| 食物 | 主要营养物质 | 平衡膳食宝塔位置 |
|------|--------------|------------------|
| 米粉 | 碳水化合物、少量蛋白质 | 第一层：谷类和薯类 |
| 猪脚 | 蛋白质、脂肪、铁、锌、维生素 B 族 | 第三层：鱼、禽、肉、蛋 |
| 葱花、酸菜、腌萝卜 | 膳食纤维、维生素和矿物质，实际用量较少 | 第二层：蔬菜和水果 |
| 卤汤中的油 | 脂肪 | 第五层：烹调油 |
| 酱油、食盐和腌菜 | 钠 | 第五层：盐 |

猪脚能提供蛋白质，但肥肉和猪皮也带来较多脂肪。卤汤、酱油和腌菜的钠含量偏高。米粉提供能量，蔬菜量却不足，因此它适合做一顿主食，不适合单独承担一整天的营养需求。

<Note type="warning" title="吃得舒服，也要控制分量">
  点餐时可以选小份米粉、少喝卤汤，并加一份烫青菜。当天其余两餐减少肥肉、油炸食品和腌制食品。需要控制体重、血脂或血压的人，应减少猪皮、肥肉和汤汁的摄入。
</Note>

*中国居民平衡膳食宝塔建议每天摄入充足蔬菜和水果，合理安排谷类、肉蛋奶豆，同时限制盐和烹调油。猪脚粉覆盖了谷类和畜肉，蔬果、奶类、豆类仍需从其他餐次补足。*

## 去菜市场怎样挑海鲜

北海美食，不一定只进餐馆。早市里的鱼、虾、蟹和贝类更接近北海人的日常餐桌。

- **鱼**：看眼睛是否清亮、鱼鳃是否鲜红，按压鱼肉后能否回弹。鱼腹破损、气味刺鼻的不要买。
- **虾**：活虾游动有力，虾身完整，头胸部连接紧。虾头明显发黑、虾壳发黏时不新鲜。
- **皮皮虾**：选择活动有力、背部饱满的。母虾腹部可能看到一条深色卵线，季节合适时肉和膏更足。
- **贝类**：轻碰后能闭壳，说明仍然存活。张口后不闭合、气味异常的应丢弃。

海鲜买回家后要尽快冷藏或烹饪。贝类需要吐沙，鱼虾要煮熟，生熟砧板和刀具分开使用。

## 为家人设计 3 天北海营养食谱

食谱保留北海味道，同时补足蔬菜、水果、奶类和豆类。分量需按家庭成员的年龄、活动量和健康状况调整。

### 第一天

| 餐次 | 食物安排 | 搭配思路 |
|------|----------|----------|
| 早餐 | 小份猪脚粉 + 烫生菜 + 无糖豆浆 | 少汤少肥肉，用青菜和豆浆补充纤维与植物蛋白 |
| 午餐 | 清蒸海鲈鱼 + 蒜蓉菜心 + 杂粮饭 | 鱼类提供优质蛋白质，杂粮饭增加膳食纤维 |
| 晚餐 | 冬瓜虾仁汤 + 香菇炒豆腐 + 玉米 | 控制晚餐油脂，补充豆制品和蔬菜 |
| 加餐 | 香蕉或当季水果 | 补充水果摄入 |

### 第二天

| 餐次 | 食物安排 | 搭配思路 |
|------|----------|----------|
| 早餐 | 越南卷粉 + 水煮蛋 + 纯牛奶 | 卷粉负责主食，鸡蛋和牛奶补充蛋白质与钙 |
| 午餐 | 白灼虾 + 番茄炒蛋 + 清炒空心菜 + 米饭 | 用白灼替代椒盐，减少油和盐 |
| 晚餐 | 海鲜粥 + 凉拌黄瓜 + 蒸南瓜 | 粥中控制海鲜和盐的用量，南瓜补充薯类 |
| 加餐 | 少糖绿豆糖水一小碗 | 保留北海糖水风味，控制添加糖 |

### 第三天

| 餐次 | 食物安排 | 搭配思路 |
|------|----------|----------|
| 早餐 | 玉米 + 鸡蛋 + 无糖酸奶 + 苹果 | 谷薯、蛋、奶和水果组合，给午餐留出海鲜空间 |
| 午餐 | 椒盐皮皮虾少量 + 清炒西兰花 + 海带豆腐汤 + 米饭 | 皮皮虾控制分量，其余菜少油少盐 |
| 晚餐 | 清蒸沙虫或贝类 + 木耳炒时蔬 + 红薯 | 海产品补充蛋白质，红薯替代部分精米面 |
| 加餐 | 一小把原味坚果 | 补充不饱和脂肪，避免盐焗和糖衣 |

<Note type="primary" title="三天搭配的重点">
  猪脚粉、椒盐皮皮虾和糖水可以吃，但不要集中在同一天。用清蒸、白灼和炖煮平衡重口味菜肴，每餐至少安排一种蔬菜，三天内覆盖鱼虾、畜肉、鸡蛋、奶类、豆制品、水果和坚果。
</Note>

一碗猪脚粉能拍到的不只是食物。卤锅里的热气、老板切肉的动作、邻桌食客的交谈、街道上刚亮起来的阳光，都属于北海的日常。

猪脚粉记录着一顿普通早餐，也保留着这座滨海城市的生活方式。
